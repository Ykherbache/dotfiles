# Chapter 3 — Values, Principles, and Practices

The three-layer framework that structures all of XP.

## The Layers

- **Practices** — concrete, objective things you do day-to-day. Clear and accountable ("you either write a test before changing code or you don't"). Give you a place to start.
- **Values** — large-scale criteria for judging what you see, think, and do. Universal but abstract. Bring purpose to practices.
- **Principles** — domain-specific guidelines that bridge the gap. Like "companion planting" bridges the value of healthy growth with the practice of planting marigolds next to strawberries.

## Key Insight

Values without practices are unfocused ("I wrote a 1000-page document because I value communication"). Practices without values become rote ("I pair program because my boss said so"). You need both, connected by principles.

## The Gardening Metaphor

Paul the master gardener vs the amateur: both know techniques (practices), but Paul has an intuitive sense of what matters (values) and understands the underlying forces (principles). Mastering XP requires practicing, joining the community, and teaching others — reading isn't enough.

## Actionable Takeaway

When a practice feels wrong, check your principles. When principles conflict, check your values. The three layers should be in alignment.
