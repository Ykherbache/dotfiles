# XP Cheatsheet

## Values
**Communication · Simplicity · Feedback · Courage · Respect**

## Principles
Humanity · Economics · Mutual Benefit · Self-Similarity · Improvement · Diversity · Reflection · Flow · Opportunity · Redundancy · Failure · Quality · Baby Steps · Accepted Responsibility

## Primary Practices
Sit Together · Whole Team · Informative Workspace · Energized Work · Pair Programming · Stories · Weekly Cycle · Quarterly Cycle · Slack · Ten-Minute Build · Continuous Integration · Test-First Programming · Incremental Design

## Corollary Practices
Real Customer Involvement · Incremental Deployment · Team Continuity · Shrinking Teams · Root-Cause Analysis · Shared Code · Code and Tests · Single Code Base · Daily Deployment · Negotiated Scope Contract · Pay-Per-Use

## Quick Decisions

| Situation | XP Says |
|---|---|
| Don't know which design to pick | Try all candidates; failure that imparts knowledge is not waste |
| Estimate is wrong | Fix the numbers, communicate consequences; it's information failure, not values failure |
| Can't make long-term plans | Use quarterly cycle; refine as you go |
| Too many defects to handle | Slow down releases until you can respond; fix root causes |
| Big system replacement | Incremental deployment; "that trick never works" for big-bang cutover |
| Need to scale up | First try smaller team; then conquer-and-divide |
| Quality vs speed tradeoff | False tradeoff — higher quality usually means faster delivery |
| Scope pressure | Scope is the control variable; time/cost are fixed; never sacrifice quality |

## Four Simple Design Rules
1. Appropriate for audience
2. Communicative
3. Factored (no duplication)
4. Minimal

## Root-Cause Analysis (Five Whys)
Defect found → write system test → write unit test → fix → ask why 5 times → fix the people/process problem

## Key Metrics (for executives)
1. Post-development defect count (should trend toward zero)
2. Time from investment to first revenue (should shrink)

## Planning Formula
`stories (items) × estimates (prices) ≤ budget (time) → negotiate scope`
